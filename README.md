# DigitalSignature

.NET 10 tabanlı dijital imza deneyleri ve geliştirmeleri.

## Yapı

- `src/DigitalSignature` → ana kütüphane
- `tests/DigitalSignature.Tests` → test projesi

## Başlangıç

```bash
dotnet restore DigitalSignature.slnx
dotnet build DigitalSignature.slnx
dotnet test DigitalSignature.slnx
```
